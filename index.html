About

The short version: I ship things, then keep them running.

I'm a Computer Science graduate from Acharya Nagarjuna University who learned to build software the way most engineers actually do — by owning real projects from the first commit to the live server. Across freelance work and internships, I've designed database schemas, built the UI on top of them, wired up REST APIs, and then handled what happens after launch: debugging, root-cause analysis, and keeping production systems stable.

That last part is where I spend a lot of my energy. At Horilla, I worked inside a live, multi-module HRMS — tracing UI and data issues across employee, attendance, and payroll modules without breaking what already worked. At GloomDev, I got hands-on with enterprise backend development using Java, Spring Boot, and PostgreSQL. Alongside that, I've independently shipped five production websites for real businesses, end to end.

I'm currently deepening my footing in cloud and networking fundamentals (AWS Cloud Practitioner Essentials) and exploring applied AI engineering — while staying grounded in the fundamentals: clean REST APIs, solid SQL, and code that's easy to debug at 2am.
